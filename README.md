## Özellikler
- Her şeye rastgele absürt vergiler uygular: Kaos, Kedi, Zaman Yolculuğu, Absürtlük ve Uzaylı vergileri.
- Gerçek Python kodu. Kopyala-yapıştır, çalıştır, gül.
- Mantık yok. Eğlence var. Vergi her zaman kazanır.

## Nasıl Kullanılır?

Miktar gir, ürün adı gir, bekle, gül, vergi öde (hayalinde).
